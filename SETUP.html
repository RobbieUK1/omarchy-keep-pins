💡 Keep Pins

Your pinned Google Keep notes in the Omarchy bar. The Open Keep ↗ button opens Keep in its own web app window.

GitHub repository & installer · Download Chromium companion ZIP

One-time Chromium setup

  1. Open chrome://extensions in Chromium and switch on Developer mode.
  2. Click Load unpacked and choose ~/.config/omarchy/plugins/robbie.keep-pins/companion (use Ctrl+L to enter the full folder path).
  3. Use Open Keep ↗ in the dropdown. Sign in to Google yourself if prompted. If Keep was already open, reload its window once.
  4. Keep the main Notes page open. Pinned titles and previews sync locally when the page changes, with a check every minute. Search, labels, archives and open note dialogs do not replace the cache.

No password or account token is collected. The companion can read Keep pages and send pinned titles and text to a local receiver. The dropdown stores these previews in your private local cache; it never edits notes. The browser companion can be disabled on the extensions page to stop syncing.

This uses Keep's web page structure, which Google can change. Initial extraction supports English pin labels and a CSS fallback. Sync needs an open signed-in Keep page in the Chromium profile where the companion is enabled. Other browsers and multiple simultaneous Google accounts are not supported in this first version: the latest synced account is shown.

If the companion icon shows !, the local receiver is missing or unavailable. Re-run the installer. If nothing appears, use Keep's English interface and main Notes page, then reload. Cached previews remain visible when Keep is closed; their status changes after two minutes. Image and drawing attachments are not downloaded.
